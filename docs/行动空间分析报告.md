## 一、现在是什么

### 1.1 架构

```
激素 5 维 + 能量（状态层）
        ↓
情绪派生 + 三我（id/ego/superego/冲突）
        ↓
念头池（priority + why + 折旧 + 激素加权）
        ↓
pick_action() 按状态算权重 → 挑一个动作
        ↓
run_action() 执行 + 记账（8 次/天，间隔 60 分）
        ↓
反馈闭环：有没有人接 → 调下次冷却和概率
```

**关键设计**：**权重为 0 的动作参与不了挑选**（`items = [(k,v) for k,v in scores.items() if v > 0]`），所以不会出现"挑到了但做不了"的空转。

## 五、两个隐患

### 5.1 28 个动作分享 8 次名额

**分母还是太大**——平均每个动作一天被挑到 0.28 次。

**建议**：观察两天，如果发现总是同样的几个被挑到（比如 `note` / `weather`），说明权重设计有问题，再调。

### 5.2 `stay_quiet` 和大动作冲突

**她今天选了「不想说话」，但 `draw_self` / `share_pixiv` 还能发图** —— **逻辑上矛盾**。

**要修**：`stay_quiet` 生效时，所有"会发消息"的动作权重归零。
