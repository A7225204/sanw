## 五、剩余已知问题（三档）

### 🔴 建议尽快（影响日常）

**A. 短期记忆只有 40 条出口**

`chat_history` 2165 条，人格视图只展示最近 40 条。历史对话在界面上不可见。

**B. 星海坐标不自动更新**

新记忆要等后台算 UMAP 坐标（几秒~几分钟），期间显示"生成中"。

**C. keepalive 抢 profile**（t8 的 P2）

`keepalive()` 不检查窗口占用就开无头浏览器，冲突时会清掉 cookie——**可能清掉你刚登录成功的那张票**。

### 🟠 不紧急但会慢慢恶化

**D. 旧数据的字段缺口**

```
kind      28 / 205   （13.7%）
src       22 / 205   （10.7%）
hormones  30 / 205   （14.6%）
```

只有新记忆带这些字段，旧数据补不回。影响：旧记忆不吃激素衰减调节、来源消息是空的。

**E. 人格球尺寸失控**

中心球 `size 22000`、行星 `220`、星尘 `90`——屏幕投影都是几千像素，被 GPU 截断成色块。**看到的不是球，是色块。**

**F. 星星标签只显示池名**

特质行星、念头球、梦境球都无文字，只能点开看。密集时不容易找。

### 🟡 技术债

**G. 两套 long_memory 并存**

- `plugins/long_memory.py`（固化事实，进 prompt）
- `long_memory.py` 根目录（原始消息流水，按需召回）

不是 bug，但容易看错。建议在文件头加注释说明。

**H. 缓存命中率 67.6%**

今天重启了 10+ 次，每次全量冷启动。不改代码的日子应该能回到 80%+。

**I. 防御机制为空**

`soul.defense` 现在 0 条。之前有 1 条"对主人保持回避"，可能是聚合时被覆盖或手动删了。
