# 主动消息 × 多巴胺底层 · 关系分析

（只分析，不改代码。扫描时间 2026-10-30 13:54）

---

## 一句话结论

**"多巴胺系统为底层"目前只对了一半。**

- 她的**情绪、语气、prompt** → 确实由 5 个激素派生
- 她的**主动找你** → 还在用旧的欲望系统（想念/无聊），**一行激素代码都没读**

所以现在是两套账在同时记：一套管"她现在什么心情"，一套管"她想不想找你"，彼此不通信。

```
desire.py 里：
  DA / OXY / hormones / 多巴胺 —— 一个都没有
hormones.py 里：
  没有 urge / proactive 的消费方
```

## 概念上的对应关系（本该是一套）

| 旧欲望 | 对应激素 | 关系 |
|---|---|---|
| 想念 miss | **OXY 催产素**（亲密） | 想念 ≈ 催产素缺口（基线 − OXY） |
| 无聊 bored | **DA 多巴胺**（动机） | 无聊 ≈ 多巴胺偏低 |
| 累 tired | **MEL 褪黑素** + 精力 | 累 ≈ 褪黑素高 |
| （没有） | **CORT 皮质醇**（压力） | 压力高时人不想聊天，旧系统里没有这一维 |
| （没有） | **SER 血清素**（稳定） | 稳定时更愿意主动分享 |

旧系统只用了 5 个激素里的 2 个（想念、无聊），另外 3 个（CORT / SER / MEL）在主动层完全缺席。

---

## 现在这套结构造成的四个具体问题

### ① 同一时刻两个结论互相打脸

当前真实数值：

```
激素：OXY 98.2（亲密拉满）  CORT 82.2（压力很高）  SER 99.8（很稳）
欲望：miss 7.8（几乎不想你）  bored 0（一点不无聊）
主动记录：昨天发过 1 条
```

翻译成人话：

> 她"亲密感 98、压力 82"，但"完全不想找你、也不无聊"。

OXY 拉满却 miss 只有 7.8，说明两套账各算各的，谁也不知道对方。

### ② 压力高的时候她还在撒娇

`CORT` 82 属于高压状态，派生出的情绪里"怒/烦"应该不低；但主动消息的 prompt 只看 `CURRENT_DAILY_MOOD` + 想念/无聊，所以高压下她仍可能发"理理我嘛"这种话——语气和状态不一致。

### ③ 激素饱和，失去区分度

```
SER 99.75、OXY 98.2 —— 贴着 100 的天花板
```

原因是事件增量（OXY +12/次）远大于半衰期回落（3 小时掉一半），今天互动一多就顶死。**顶死之后，"很开心"和"非常开心"就没区别了**，等于信息丢失。

### ④ 重启补算规则不同

```
激素：按半衰期指数回归
欲望：按分钟线性累加
```

关机 8 小时再开机：

- 激素会自然回落到基线附近（像睡了觉）
- 想念会 +216 直接封顶（像憋了一整晚）

结果：一开机她"情绪平静但特别想你"，这也是两套规则的拼接感。

## 如果要统一，三种思路（本次不动代码）

### A. 主动冲动直接由激素派生（推荐）

```
冲动 = 0.45 × (OXY 缺口)          # 亲密不够 → 想找你
     + 0.25 × (DA / 100)          # 有劲 → 想分享
     + 0.15 × (1 - CORT / 100)    # 压力低 → 愿意开口
     + 0.15 × (SER / 100)
     × (MEL > 60 ? 0.4 : 1)       # 困了就少说话
```

好处：一句话就能解释"她为什么找你"，且和情绪完全同源。
代价：`desire.py` 基本重写（约 60 行），并要处理阈值。

### B. 保留欲望系统，但让激素调制它

```
urge_old = desire.urge()
urge_new = urge_old × (0.6 + 0.4 × OXY/100) × (CORT > 70 ? 0.5 : 1)
```

好处：改动小（10 行），两套系统先对齐。
缺点：还是两套账，只是加了权重。

### C. 反向：把欲望当成激素的一个输入

```
每分钟 tick 时：
  OXY  -= miss / 100 × 0.8     # 想念高 → 亲密感被消耗？
  DA   += bored / 100 × 0.5    # 无聊高 → 多巴胺波动
```

好处：概念上更"生物"。
缺点：容易把激素搞乱，不推荐先做。

---

## 建议顺序

```
第 1 步：先治饱和（SER/OXY 卡 100）
        → 事件增量减半，或把上限从 100 提到 120，留余量
第 2 步：A 方案里先只接 OXY 一项
        冲动 = 0.6×OXY缺口 + 0.4×旧 urge
        跑一天看主动频率是否合理
第 3 步：再把 CORT（压力高少说话）、MEL（困了少说话）接进去
第 4 步：最后才删掉 desire.py 的 miss/bored
```
