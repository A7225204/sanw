# 方案 A：把状态层统一成「内分泌」（5 个激素量）

> 目标：不是让她"更聪明"，而是让她的情绪 / 主动性 / 生理状态**同源**，行为不再自相矛盾。
> 现状：情绪 7 维（`emotion_state.json`）、欲望 3 驱动（`desire_state.json`）、生理（`meal_state` / `sleep_state`）三套各自独立算。

---

## 1. 架构：三层

```
第 0 层（真源）  5 个激素量，0~100，各自有基线 / 半衰期 / 交叉影响
第 1 层（派生）  7 维情绪 = 激素的线性组合（现有 prompt / mood_mode 一行都不用改）
第 2 层（输出）  prompt 注入、主动频率、语气模式、记忆权重、表情包倾向、TTS 语速
```

关键点：**情绪降级为派生量**，不再独立配置。调用方（`ai_group.emotion_prompt()`、`_refresh_mood()`、`mood_mode()`）接口保持不变。

---

## 2. 五个激素

| 量 | 含义 | 基线 | 半衰期 | 主要来源 | 主要去向 |
|---|---|---|---|---|---|
| **DA** 多巴胺 | 动机 / 兴奋 | 40 | 25 min | 被夸、出图唱歌成功、主人回应 | 提高主动性、缩短回复长度、记忆权重↑ |
| **CORT** 皮质醇 | 压力 / 烦躁 | 20 | 120 min | 被骂、被无视、群聊对线 | 触发暴躁模式、降低催产素、压低血清素 |
| **SER** 血清素 | 稳定 / 满足 | 55 | 240 min | 吃饭、睡好、平稳聊天 | 抵消皮质醇、抑制"丧"和"烦" |
| **OXY** 催产素 | 亲密 / 依恋 | 35 | 180 min | 主人私聊、被摸头、长时间陪伴 | 想念驱动、撒娇倾向、害羞 |
| **MEL** 褪黑素 | 睡意 | 15 | 60 min（按作息驱动） | 深夜、困、午夜后 | 累、减少主动、压低多巴胺 |

常量都放模块顶部，方便调；每个量 `clamp(0,100)`，并且**每小时强制向基线回归**（防止漂移成永久愤怒或永久亢奋）。

---

## 3. 派生公式（第 1 层）

以 0~100 计，先算偏离量再裁剪：

```
开心 = clamp( 0.55·DA + 0.30·SER − 0.20·CORT + 12 )
害羞 = clamp( 0.50·OXY + 0.20·DA − 0.25·CORT + 4 )
烦   = clamp( 0.55·CORT + 0.25·MEL − 0.20·SER + 8 )
怒   = clamp( 0.70·CORT − 0.25·SER + 0.15·DA + 5 )
丧   = clamp( 0.45·(100−DA) + 0.30·(100−SER) − 0.20·OXY + 6 )
累   = clamp( 0.55·MEL + 0.25·(100−ENERGY) + 0.15·(100−SER) )
害怕 = clamp( 0.55·CORT − 0.20·SER + 0.15·(100−OXY) )
```

保留 ±3 的随机噪声，避免数值看起来太"机械"。

旧 `EMOTION_COUPLING` 矩阵在迁移完成后**停用**（耦合已经由激素层承担，避免双重放大）。

---

## 4. 事件 → 激素（现有入口挂 5 个钩子）

| 事件（现有代码位置） | DA | CORT | SER | OXY | MEL |
|---|---|---|---|---|---|
| 主人私聊（`private_ai` 入口） | +6 | −10 | +2 | **+12** | 0 |
| 群友 @ / 群聊互动（`ai` 入口） | +2 | +1 | +1 | +1 | 0 |
| 被骂 / 被威胁（`mood_mode` 判定处） | −4 | **+15** | −5 | −3 | 0 |
| 被夸 / 撒娇成功 | **+10** | −4 | +5 | +3 | 0 |
| 吃饭（`meal_state` 写入时） | +3 | −3 | **+8** | +4 | 0 |
| 睡觉 / 醒来（`sleep_state` 写入时） | −5 | −8 | +6 | 0 | ±20 |
| 唱歌 / 画图成功（`sing_song` 成功分支） | **+12** | −2 | +3 | +2 | 0 |
| 长时间无互动（tick 累积） | −0.05/min | +0.05/min | −0.03/min | **−0.10/min** | 0 |
| 深夜 23:00~06:00（tick） | −0.10/min | 0 | 0 | 0 | **+1.2/min** |

交叉影响（每 tick 施加，系数小）：

```
SER → CORT  −0.06    皮质醇被血清素缓冲
DA  → CORT  −0.04    兴奋能压住压力
CORT→ OXY   −0.04    压力大时不想亲近
MEL → DA    −0.05    困了没兴致
```

---

## 5. 输出（第 2 层）——真正改变行为的地方

| 输出 | 怎么用 | 影响 |
|---|---|---|
| **prompt 行** | 把现有 `emotion_prompt()` 输出从「7 维百分比」扩成「5 激素 + 7 情绪」一行，长度 ≈ 40 字 | token 增量 < 20/轮 |
| **主动性** | `desire.想念` 改为 `OXY 缺口 + DA` 计算，频率阈值再被 CORT 调制 | 她"想不想找你"有因果 |
| **语气模式** | `mood_mode()` 判定改为看 CORT/SER 区间（狂躁、嫌弃、撒娇） | 对线/撒娇切换更自然 |
| **记忆权重** | `add_learned / _apply_ops` 写入时 `w *= 0.75 + 0.5·DA_norm` | 兴奋时记得更牢（配合艾宾浩斯） |
| **分条节奏** | DA 高 → 分条更快、句子更短；CORT 高 → 更短更冲 | 打字感更像人 |
| **表情包倾向** | DA 高偏 happy 类，CORT 高偏 angry 类 | 图也更贴状态 |
| **TTS 语速（可选）** | DA/MEL 映射 rate ±8% | 说话节奏随状态变 |

## 7. 迁移与灰度

1. **影子模式**（不改行为）：激素层并行运行，只写日志，3 天对比它与现有情绪的偏离度。
2. 用现有 7 维反推初值：

```
DA   = 开心 × 0.8 + 害羞 × 0.4
CORT = max(怒, 烦) 
SER  = 100 − 丧
OXY  = 害羞 × 1.2 + 开心 × 0.3
MEL  = 累
```

3. 确认合理 → 切换 prompt 来源（第 2 层先只改 prompt，不改行为），观察 3 天。
4. 再逐个打开行为钩子（主动性 → 语气 → 记忆权重 → 表情包）。

每步都能用环境变量回滚：`HORMONES_ENABLED=0` 立即回到现有实现。

---

## 8. 验收指标（3 天 A/B）

```
情绪分布熵        不能比现在低（防止长期卡在"丧"或"怒"）
主动私聊率        与想念驱动相关性 > 0.5
平均回复长度      波动方差变大（有起伏才像人）
重复/复读率       不上升
prompt token      增幅 < 2%
主观              你能否说出"她今天状态不一样"且合理
```

---

## 9. 风险与对策

| 风险 | 对策 |
|---|---|
| 数值长期漂移（永远暴躁） | 每小时向基线回归 + clamp + 上限锁 |
| 和旧 coupling 双重计算 | 迁移时关闭 `EMOTION_COUPLING` |
| prompt token 变多 | 压缩成一行，只留 5 个整数 + 7 个百分比 |
| 重启丢状态 | 落盘 + 按"距上次 tick 时长"补算（照抄 desire.py 现有做法） |
| 过度工程 | 分 5 步上线，每步可回滚；影子模式先行 |
| 看起来"太科学"反而假 | 保留随机噪声；不把激素数值直接说给她听 |

---

| 阶段 | 内容 | 预估 |
