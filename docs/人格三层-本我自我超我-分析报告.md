# 本我 / 自我 / 超我 · 人格完善分析报告（2026-11-03）

> 问题：按弗洛伊德的三层人格结构，能不能让大肥鱼的人格更完善？
> 结论先行：**能，但增量不在"分三层"，在"三层打架"。** 你已经有全部零件，缺的是碰撞。

---

## 一、现状盘点：你已经有一半了

| 层 | 你已有的实现 | 位置 |
|---|---|---|
| **本我**（欲望/冲动） | 五激素 DA/CORT/SER/OXY/MEL、三欲望 miss/bored | `plugins/hormones.py`、`desire.py` |
| **自我**（现实决策） | 回复优先链、回不回/怎么回/什么语气、`withdraw` 回避档 | `plugins/ai_group.py`、`withdraw.py` |

**关键发现**：人格视图里的"本我"（中心恒星）目前是**空壳**——

`soul_aggregation.py` 的注释写得很清楚：

> 中心恒星 = 这些 traits/rules 的**整体情绪基调**

也就是说，中心球不是"本我"，是"超我的加权平均色"。真正的本我（激素、欲望）在另一个文件里，**跟视觉结构没有连接**。

## 二、三层映射表（如果真要做）

| 弗洛伊德 | 在你系统里的具体载体 | 现在缺什么 |
|---|---|---|
| 本我 Id | 激素值 + 欲望值（她"想要"） | 没有"欲望的具体诉求"（想被夸/想被抱/想安静） |
| 自我 Ego | `ai_group` 决策链（她"决定"） | 决策是隐式的，没有"我忍住了"这个中间态 |
| 超我 Superego | traits/rules/defense（她"应该"） | 准则只是 prompt 里的文本，**不参与运行时的冲突判定** |

你有一个很妙的证据：**traits 里已经有「嘴硬心软」**。

这个词本身就是"本我想黏 + 超我说不能舔"的产物——但它现在是**被聚合出来的静态标签**，不是**运行时的冲突**。她说话时并不真的在"嘴硬"和"心软"之间拉扯，只是读到这个词然后演出来。

这就是现状和"真三层"的差距。

## 三、弗洛伊德模型真正的价值：不是分层，是冲突

如果只是把现有东西贴三个标签（"这是本我、这是自我、这是超我"），**零增量**，还会让 prompt 多三行废话。

真正的增量是这三个机制：

### 1. 显式冲突检测

每轮聊天前做一次判断：

```
本我信号（OXY 高 → 想黏人 / miss 高 → 想找他说话）
        ×
超我信号（准则：傲娇不能说太软 / 被骂不翻脸）
        ↓
冲突强度 0~1
```

冲突高时，她才"真的在犹豫"，而不是"演嘴硬"。

### 2. 冲突改变表达，而不是加解释

- 冲突高 → 说话更短、更别扭、口是心非（"谁想你了…本鱼只是刚好在"）
- 冲突低 → 直接表达

**不要**让她说"我心里有两个声音在打架"——那是 AI 味。冲突应该体现在**语气**上，不是**自述**上。

### 3. 自我消耗：压制本我 → 压力上升

长期"想黏但忍住" → CORT 涨。这解释了"她为什么莫名烦躁"——不是随机情绪，是自我消耗。

这条和你 11-03 刚做的"热度折扣 + 每日上限"是同一个方向：**让情绪有代价**。

## 四、轻量实现方案（不新建大结构）

### 方案 A（推荐，半天）

加一个 `plugins/ego.py`，只做三件事：

1. **`conflict()` 函数**：读当前激素/欲望 + soul 准则，输出 `(强度, 类型, 一句话)`
   - 例：`(0.7, "想黏人vs傲娇", "想找他说话，但不想显得太主动")`
2. **注入 prompt**：只在冲突 > 0.5 时加一行（≤25 字）
3. **面板**：把中心球从"情绪基调"改成真正的"本我"（激素/欲望的可视化），三层颜色区分

### 方案 B（轻，2 小时）

不新建文件，只在 `ai_group.build_system_prompt` 里加一段模板字符串：

```
【此刻的拉扯】
你现在{本我诉求}，但你的原则是{命中准则}。说话会别扭一点，别解释。
```

由现有的 `hormones.prompt_line()` + `soul.rules` 拼出来。

**我推荐 A 的 1+2 + B 的注入**：结构小、可回退、不碰现有数据。

## 五、风险与边界

| 风险 | 说明 | 对策 |
|---|---|---|
| prompt 膨胀 | 每轮多 25~50 字，缓存前缀可能失效 | 放 volatile_prompt（每轮可变的段），不动 ① 稳定前缀 |
| AI 味 | 让她自述"我在挣扎"会立刻出戏 | 只改语气，不让她解释 |
| 理论硬套 | 弗洛伊德不是工程规格 | 只取"冲突"这一个可计算的东西 |
| 维护成本 | 已有 54 插件 | 不新建大文件；`ego.py` 控制在 150 行内 |

---

## 六、结论

1. **能做，但别为了"三层"而三层**——你已经有三层的零件，缺的是"碰撞"。
2. **最值得做的**：一个 50 行以内的冲突检测器，把"本我冲动 vs 超我准则"变成每轮一次的判断，高冲突时只改语气。
3. **第二值得做的**：把人格视图的中心球从"情绪平均色"改成真正的本我（激素/欲望可视化）——这让三层在**视觉上**成立。
4. **不值得做的**：给三层各建一套 JSON、让 AI 自述心理活动、把弗洛伊德写成 prompt 课文。

> 一句话：**人格的完善不在于多一层标签，而在于让"想做的"和"该做的"真的打架，并且让用户看得出来。**
