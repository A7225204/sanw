她回一句话，这四层各做什么

1

L1 把刚说的话原样存下，同时回填最近 N 条进上下文

2

L3 按这句话语义找相关的旧记忆（字面匹配不上的也能捞到）

3

L2 按 scope 取全量档案 + 相关条目，从不截断，只重排

4

L4 桌宠那条线单独注入 2.5k 字的人设+近况

四种闸门，四种用途

L1 —— 不许改，原始证据
L2 —— 要提炼，一句话一件事
L3 —— 要相似，跨字面找
L4 —— 要压缩，塞得进 prompt

设计上的一条硬规矩

!

prompt 注入只重排不截断 —— 顺序是 人设 → 自学 → 档案 → 词条，永远不会把档案整段砍掉

!

L2 的 archive_text 与查询无关（缓存稳定），archive_related 才看 query
