## 二、为什么原来的做法会学歪

### 之前

```python
query = 念头原话[:20]      # 整句口语直接当搜索词
rows = await _free_web_results(query)
```

**实测灾难**：

| 念头原话 | 实际搜成 | 拿回来什么 |
|---|---|---|
| 发发色图 | "头发 颜色" | 我图网发色素材专题 |
| 方便从后面 | 原句 | 色情段落两段 |
| 那描述下 | 原句 | 一堆无关页面 |
| 发图片 | 原句 | "怎么在QQ发图片"教程 |
| 先发图 | 原句 | "1个回答 - 3人关注 - 5513次浏览" |

**22 条"知识"里 17 条是这种。** 而且这些垃圾会一路走到人格提炼。

### 根因两条

1. **口语 ≠ 查询词** —— 搜索引擎不认识"那描述下"
2. **不是每个念头都值得学** —— "主人今天不理我" 是情绪，不是求知

## 四、第 ①关：值不值得学

### 硬性跳过（`_NOT_A_QUERY`）

```python
_NOT_A_QUERY = re.compile(
    r"^(发|给|来|看看?|下载|找).{0,4}(图|片|视频|资源|链接)"
    r"|(发|给|来).{0,3}(色图|涩图|黄图)"
    r"|^(那|这个|那个|这样|那样)", re.I)
```

**判定逻辑**：**要图 / 要资源 / 指代不明 → 不是学习，是索取。**

### 模型判断（兜底）

提炼 prompt 里明确写：

```
3. 如果这句话其实不是想搞懂什么（只是抱怨、撒娇、要东西、闲聊、重复语气），输出 NONE。
```

### 实测

| 念头 | 判定 |
|---|---|
| 发发色图 | 跳过（要东西） |
| 方便从后面 | 跳过（不是求知） |
| 那描述下 | 跳过（指代不明） |
| 发图片 | 跳过（要东西） |
| 主人今天不理我 | 跳过（情绪） |
| 想看片 | 跳过（要东西） |
| 缅北反诈是什么 | ✅ 学 |

## 五、第 ②关：变成什么查询词

### 5.1 三条路，优先级从高到低

```
情欲类 → 固定主题库（16 条，按意图选）
```

### 5.2 情欲类：不搜原句，搜主题

**16 条主题库，分六组**：

| 组 | 主题词 | 触发意图 |
|---|---|---|
| **技巧** | 性爱技巧 前戏方法 / 两性关系 节奏配合 身体接触 / 如何增加亲密感 日常触碰 | 前戏、怎么弄、体位、节奏、持久、舒服 |
| **沟通** | 亲密时怎么沟通 性需求表达 / 性爱后怎么聊天 事后温存 / 怎么跟伴侣说自己的喜好 | 聊什么、说什么、尴尬、事后 |
| **同意** | 如何询问对方意愿 性同意边界 / 怎么拒绝而不伤感情 / 亲密关系里的边界感 | 拒绝、不想、停、边界、同意 |
| **安全** | 安全措施 避孕方式 科普 / 性健康 常见误区 科普 | 避孕、怀孕、套、健康 |
| **关系** | 长期关系 亲密感变淡 怎么办 / 异地恋 维持亲密 方法 / 第一次 注意事项 心理准备 | 久了、变淡、异地、第一次、紧张 |

**为什么这么设计**：

- **搜"性爱技巧"** → 出来的是两性科普、情感专栏
- **搜原句** → 出来的是色情段落
- **她要的是"知道怎么做/怎么说"，不是图文**

**实测**：

```
性爱的时候该怎么说话   → 亲密时怎么沟通 性需求表达
前戏要怎么做          → 性爱技巧 前戏方法
做爱后聊什么不尴尬     → 亲密时怎么沟通 性需求表达
怎么拒绝对方不伤感情   → 怎么拒绝而不伤感情 亲密关系
避孕有哪些方式        → 安全措施 避孕方式 科普
第一次要注意什么       → 第一次 注意事项 心理准备
```

## 七、第 ④关：收回来怎么过滤

### 7.1 搜索结果层

```python
piece = 摘要.strip()
piece = re.sub(r"^\d{4}年\d{1,2}月\d{1,2}日\s*[·・.]\s*", "", piece)   # 去日期前缀
if len(piece) < 12: continue      # 太短不要
lines.append(piece[:110])
if len(lines) >= 2: break         # 最多两条，宁缺毋滥
```

### 7.2 入库层质量门（`_valid_fact` + `_JUNK_FACT_RE`）

**挡掉六类垃圾**：

| 类别 | 特征 |
|---|---|
| **企业信息 / 备案号** | 为您提供、查询服务、工商注册、网信算备、ICP备、公网安备 |
| **素材站 / 标题党** | 我图网、摄图网、千图网、堆糖、花瓣网、素材专题、图片大全、免抠元素、眼界大开、越看越懵 |
| **页面头部文案** | 名玩家向您推荐、点击前往哔哩哔哩、视频播放量、投币、个回答、人关注、次浏览、来自 iPhone、正在加载、请稍候 |
| **盗版影视站** | 在线看完整版、高清完整片源、多端同步观看、随时随地追剧 |
| **搜索结果说明** | 提供详尽的搜索结果、每天实时更新、连接人与信息 |
| **无效学习** | 无法核实、没有关于、搜索无结果、查不到、只解释了、无相关信息 |

**实测**：22 条里筛掉 6 条（涉性 2 条、教程 2 条、闲聊 1 条、重复 1 条），留下 7 条。

## 八、第 ⑤关：存成什么

### 8.1 两种时效

| kind | 判定 | 有效期 |
|---|---|---|
| **news** | 有时效/进度标记（今天/本周/开赛/发布/在追/已看到第…） | **7 天** |
| **knowledge** | 其余（概念、常识、技能） | **常驻不过期** |

**为什么分**：《资本论》《庞氏骗局》这类常识学完一周就死，等于白学 —— 2026-11-05 改的。

### 8.1b 学完先自己嚼一遍（2026-11-06 23:33 加）

**以前**：搜索摘要原文直接进库。

```
fact = "缅北反诈是什么：缅北最严厉的父亲指一个专门陪骗子聊天、主动引诱套取线索的反诈项目，其公司仅20人，还拿了千万美元融资"
```

**那是别人的话，她只是搬运。**

**现在**：先让她用自己的话说一遍，存的是她嚼过的那句。

```python
_DIGEST_PROMPT = (
    "你刚查到这些资料：
{body}

"
    "用你自己的话写一句「我学到的」，20~45 字，像突然想通了在嘟囔：
"
    "- 不要念来源，不要说「根据搜索」，不要照抄原句
"
    "- 说人话，可以带一点自己的口气，但别加表情符号
"
    "- 如果这些资料其实什么都没讲清楚，就输出 NONE
"
    "只输出这一句。"
)
```

**实测同一批摘要**：

| | 内容 |
|---|---|
| 原文 | 缅北最严厉的父亲指一个专门陪骗子聊天、主动引诱套取线索的反诈项目，其公司仅20人，还拿了千万美元融资 |

**再加一层保险**：总结也要过质量门（`_valid_fact`），不过就退回原文，至少不丢。

**原文摘要存进 `evidence` 字段**（`ev`），随时能核对总结有没有失真。

## 九、第 ⑥环：怎么进人格

### 9.1 之前的断点

**人格提炼只看三样**：

```python

```

**`global_learn` 一次都没出现过。** 学得再多也长不成人格。

### 9.2 现在接上了

```python
def _learned_lines(limit=6):
    """她自学过的知识（只取 knowledge 类）"""
    for it in lm._archive.get("global_learn") or []:
        if str(it.get("kind")) != "knowledge":   # news 是 7 天热搜，不参与塑形
```

**prompt 里加的段落**：


## 十、她"知道怎么搜"体现在哪

**不是靠模型每次自由发挥，是靠三层确定性**：

1. **规则层**（正则）—— 一眼能认出来的，直接套模板，不烧 token
2. **主题层**（16 条性 + 8 个域）—— 敏感/常见话题有固定正确问法
3. **模型层**（兜底）—— 只有前两层都不认识时才问模型

**这样"知识类"她懂怎么搜，"色情类"她搜的是技巧和沟通而不是图。**
