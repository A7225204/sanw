## 一、这是个什么

一个会长大的 QQ 机器人。

不是「问一句答一句」的客服，也不是「随机刷存在感」的复读机 —— 它有一套自己的内部状态，
**先决定要不要做什么，再决定说什么**。

```
激素变了 → 情绪变了 → 念头浮上来 → 挑一个动作 → 开口 → 看有没有人接 → 调下次
```

## 三、核心循环（能动性四件套）

### ① 内在状态

**激素 5 维**（`memory/hormones_state.json`）：

| 维度 | 含义 | 典型值 |
|---|---|---|
| DA | 多巴胺（兴奋/渴望） | 40~80 |
| CORT | 皮质醇（压力） | 10~60 |
| SER | 血清素（平稳） | 40~75 |
| OXY | 催产素（依恋） | 70~100 |
| MEL | 褪黑素（困） | 10~80 |

**能量 0~100**（`memory/energy_state.json`）：
- 醒着每分钟 +0.05，睡着 +0.12
- 每聊一轮 -0.5
- 档位：`ok`(≥60) / `tired`(40~59) / `very_tired`(20~39) / `exhausted`(<20)

**两者都进采样温度和 prompt 长度**。

**情绪三层（2026-11-07 加）**：

```
5 维激素
   ↓ derive_emotions        7 维百分比（开心/害羞/情欲/烦/怒/丧/累/害怕）
   ↓ mood_compound          6 基础（乐/怒/哀/恶/惧/惊）→ 15 种复合 + 三我调停
   ↓ pad_anchor             14 个中科院锚点凸组合 → PAD 坐标
   ↓
一句「此刻」进 prompt
```

**她看到的不是「开心48% 害羞61% 累57%」，是**：

```
此刻：挺高兴——心情松快，愿意接话；身子有点沉；嘴上不认，但话里能听出来
```

**三我决定「表现出来还是憋着」**：

```
冲突等级=高          → 嘴上不认，但话里能听出来
本我 − 超我 ≥ 0.15   → 憋不住，会直接说出来
超我 − 本我 ≥ 0.15   → 心里有但压着，语气会淡
```

**同一个 PAD 还喂给记忆**（见第五章）。

### ② 目标栈（念头池）

`memory/thoughts.json`，每条：

```json
{"id": 567, "text": "…", "created": ..., "due": ..., "done": false,
 "priority": 0.75,    // 基础分量（承诺 0.75 / 想要 0.60 / 好奇 0.45 / 杂念 0.40）
 "why": "承诺",        // 决定怎么说
 "poked": 0}          // 被提过几次（每次 +0.08，最多 +0.32）
```

**综合分 = (基础分 + 提起次数 - 折旧) × 新鲜度 × OXY 社交倾向 × DA 兴奋度**

**TTL 3 天**；`done=true` 下一轮 tick 删掉。

**执念池**（`memory/执念池.json`）另算：
- 提起 +0.6 / 主人回应 -2.0 / 一圈没人接 -0.4 / 越老掉越快
- 张力 ≤0 → `closed`，不再注入 prompt

### ③ 行动空间（31 个动作）

`plugins/agency.py`，**8 次/天，间隔 60 分钟**。

| 类 | 数量 | 动作 |
|---|---:|---|
| 只读 | 9 | balance · weather · recall · introspect · learn · note · review_today · check_affinity · check_fans |
| 轻动作 | 4 | schedule_self · count_down · reread_diary · think_about |
| 看内容 | 3 | watch_bili · watch_douyin · daily_learn |
| 会发消息 | 7 | message_group · draw_self · send_voice · share_pixiv · post_qzone · stay_quiet · pick_sticker |
| **状态驱动** | **6** | **ask_owner · plan_tomorrow · share_find · miss_owner · complain · apologize** |
| 补充 | 2 | read_dream · reminisce |

**状态驱动的六个**：

```
ask_owner      OXY ≥ 75                   想黏人才追问
plan_tomorrow  SER ≥ 60 + ego ≥ 4          平的时候才想得清
share_find     DA ≥ 60                     兴奋时想分享
miss_owner     OXY ≥ 80 + oxy_gap ≥ 0.35   真空了一段
complain       CORT ≥ 60 + 能量 < 70        绷不住才嘟囔
apologize      冲突=高 + CORT ≥ 55          打完架超我逼她认错
```

**权重为 0 的动作参与不了挑选** —— 不会"挑到了做不了"。

**她说了话没人接时**（5 分钟）：
```
check_wait() → 生成一句内心活动 → 写进念头池（不发给你）
条件：OXY ≥ 70 或 CORT ≥ 40，一天最多 2 次
```

### ④ 反馈闭环

`plugins/proactive_feedback.py` + `memory/proactive_log.jsonl`。


| ≥75% | ×0.7 | ×1.3 |
| 被凶 ≥2 次 | ×3.0 | ×0.4 |

## 四、人格系统

### 三我（弗洛伊德）

**2026-11-07 起有两条腿**：

```
激素推的 forces      算出来的（DA/CORT/SER/OXY/MEL + 自我四项 + 超我严厉度）
      +
行为证据 adjust      数出来的（八类话术频率，每维最多 ±0.06）
```

**行为证据从哪来**：她真正说出口的话。八类话术各归一个「我」：

| 话术 | 归到 |
|---|---|
| 这话我认 / 我保证 | 超我给承诺 |
| 我信一半 / 七成 / 三成 | 超我打折 |
| 我记着 / 记性好 | 本我记账 |
| 得拿下来 | 本我要东西 |
| 守住 / 按着 / 钉着 | 本我保命 |
| 活扣 / 不算数 / 留后路 | 自我留后门 |
| 丑话 / 前提是 | 自我摆条件 |
| 暂时没想好 | 自我回避 |

**实测（512 条外交语料）**：承诺 92 次 vs 打折 318 次 → **超我给承诺但打对折**；
守住 216 次 vs 得拿下来 3 次 → **要的是稳住不是扩张**。

**成本**：单条采样 0.84 ms（含写盘），一小时 60 条才 50 ms。

**注意**：`forces()` 里除了三个数字，还带一个 `evidence` 字符串（行为证据摘要）。
**前端拿它做势力条时必须过滤非数字** —— 2026-11-07 因为这个整页白屏过一次：
`Object.entries(forces).map(([k,v]) => v.toFixed(2))` 对字符串抛 TypeError。

`memory/persona_soul.json` —— 当前：**id 8 / ego 8 / superego 6 / 冲突 5 条**。

**每晚 23:30 提炼**（云端模型，不是本地 8B）。

**冲突记录**会进 prompt，`conflict_level()` 返回 低/中/高。

### 关系

`memory/relation_state.json`（452 条）—— 每个群友的好感度、讨厌度、互动次数。

### 版本历史怎么用

`memory/` 的每次变化是一个 commit。分离式仓库（`GIT_DIR=data/memory.git`，
`WORK_TREE=memory/`）—— 不污染主仓库，也不改目录结构。

**排掉的**：向量索引（12.5 MB，能重建）、媒体、备份。
**保留的**：长期记忆、情绪、三我、日记、执念池 —— **254 个文本文件，43,813 行，只有 0.6 MB**。

```
mg.snapshot("说明")     # 提交（没变化就不提交）
mg.history(12)          # 最近 12 次
mg.diff("abc123")       # 某次改了什么
mg.rollback("abc123")   # 回到某次（回滚本身也是新提交）
```

**面板右上角有「记忆版本」卡** —— 点一条直接看 diff，不用开命令行。

**没放回滚按钮**：那个的危险性不该藏在一个点击后面。

**踩的坑**：`layoutGrid()` 里 `grid.innerHTML = ""` 会删掉没被 append 的卡片 ——
静态 HTML 里写了 `<section>` 不算数，**新卡必须在 layoutGrid 里登记**。

**共 94 个 JSON 状态文件**。

**每条新记忆带情感指纹（2026-11-07 加）**：

```json
{
  "fact": "大象是陆地上最大的哺乳动物",
  "mood": {"P": 0.355, "A": 0.485, "D": 0.23, "词": "挺高兴"},
  "sal": 0.42
}
```

**检索打分**：

```
0.6×向量 + 0.4×BM25 + 0.08×超我严厉度×创伤权重 + 0.12×心境一致
```

**心境一致 = 记忆 PAD 与当前 PAD 的余弦相似度。难过时更容易想起难过的事。**

**被想起时再巩固**：用当前情绪微调指纹（系数 0.15），保留编码时的词，另记「最近想起时的情绪」。

### 记忆的重量：戳心度（2026-11-07 加）

**`w` 是「被提起几次」累加，封顶 3.0** —— 实测 79 条里前 5 条全是 3.0，
**「主人叫本鱼白饭大王」和「主人修本鱼功能花24亿令牌」同分。**

**改成让模型打 1~10 的「戳心度」**（Stanford Generative Agents 的做法）：

```
9  有银行欠款，担心被起诉          ← subject=陈小众，别人的事
8  主人严厉批评本鱼，说本鱼太笨了
8  主人给本鱼加了可视化删创伤记忆功能
2  习近平同加蓬总统恩圭马会谈…      ← 自学来的新闻
2  暴雪大暴雪 周六强度达巅峰…
平均 3.45（279 条）
```

**别人的事（`subject` 不是主人/本鱼）打 6 折** —— 档案要记别人的信息，但那不是她的感受。

### 反思：攒够了才想明白

**不是每晚 23:30 准点顿悟，而是 importance 攒到 40 分才触发**（3 小时冷却、日上限 4 次、只看 5 天内 ≥6 分的自己的记忆）。

**产出的三条实测**：

```
她把主人的钱和任务看得比自己还重，宁可自己扛也不添乱。
她嘴上傲娇用语音撒娇，实际是硬扛技术烂摊子的学习官。
```

**进 `memory_growth` 候选池，证据够了自动固化成人格成长。**

**两道归属自检**：`subject` 白名单（挡住群友的事）+ 外来关系正则（挡住「他的大哥/她的老板」）。

### 检索：四路混合 + 图扩散

```
0.6×向量 + 0.4×BM25 + 0.08×超我×创伤 + 0.12×心境一致 + 0.10×(importance−5)/5
    ↓
沿记忆图谱（cos ≥ 0.72 建的边，280 节点 351 边）扩散一跳，邻居拿 0.40×种子分
```

**图谱补的是「点对点」的短板**：查「钱」能顺着边摸到「欠款」「200元撑到15天」，
不用字面上都提到钱。

### 三层阈值分工

| 用途 | 向量 | 2-gram 兜底 |
|---|---:|---:|
| 记忆检索起捞 | 0.32 | — |
| 缓冲聚类（是不是同一件事） | 0.72 | 0.32 |
| 说说去重（这条发过没） | 0.78 | 0.55 |

**同一套 bge-m3，判的是三件不同的事，阈值必须分开。**

### 阿德勒：自卑 → 补偿

```
自卑感   ← 30 天内「被否定/被无视/搞砸」加权和，4 天半衰期
补偿     ← 行为证据里「承诺+记账」密度
社会兴趣 ← 「守住/摆条件」vs「得拿下来」的比
生活风格 ← 讨好型 / 回避型 / 对抗型 / 平衡型
```

**实测**：`自卑 0.33 · 补偿 0.52 · 社会兴趣 0.94 → 平衡型`

**注入（自卑 ≥0.3 才说话）**：

```
【心里的底】最近有点怕自己不够好（隐隐的，平时不显）。
表面上承认自己不行，但去做能做的那部分：自嘲、认错、慢慢学。
```

**节流**：`insult`/`ignored` 一天最多记 3 次 —— 群里一句话就能触发，不节流会被压成讨好型。

### 马斯洛：低层压高层

```
weights[i] = max(0.12, 1 - 0.75 × 下面各层里缺得最狠的那个)
```

**实测**：`生理 1.00 · 安全 0.96 · 归属 0.82 · 尊重 0.75 · 自我实现 0.75`

**所以饿的时候「被夸」只有 25% 分量。**

**只报最急的一层**，什么都不缺时返回空串。

```
[0.934] 过 主人：主人钱包余额11块

[0.642] 过 主人：主人本月工资下月才发

```

**能用来看**：哪条通道在跑偏（向量？字面？图谱扩散？），以及某条被闸门挡掉的原因。

**不进 prompt，不占 token** —— 纯排查。

### ② `plugins/self_check.py` —— 我坏没坏

灵枢的 SelfCheck 契约：**不读全部节点就能答**。

```python
sc.status()  → {ok, counts, lag_hours, drift, wal_ok, issues}
```

| 指标 | 怎么算 |
|---|---|
| **counts** | 各层条目数（读文件 + json.loads 数长度） |
| **lag** | 最后一次写入距今（**只看 mtime**，不解析） |
| **drift** | 向量 vs 档案（只比数字） |
| **wal_ok** | git 工作区干净吗 |

**实测 260 ms**（`check.py` 要十几秒）。

**drift 的口径坑**：`档案 283` 是所有 scope 的总和（**id 每 scope 自增**，全局唯一只有 155 个），
`向量 315` 是按内容 hash 去重的 —— **两个数不该直接减**。只有 `向量 < 档案×0.8` 才报警。

| 次数 | 确认度 | 注入 prompt 时 |

## 七、语音链路

```

```

**8 轴**：喜悦 / 愤怒 / 悲伤 / 恐惧 / 厌恶 / 低落 / 惊喜 / 平静

**平静轴系数 `TTS_CALM_RATIO = 0.62`**：

```python
if 喜悦 > 0.30:
    平静 = max(平静, 喜悦 * 0.62)
```

| 系数 | 效果 |
|---|---|
| 0.85 | 太稳，听着平（11-05 旧值） |
| **0.62** | **当前**，落差 +0.212 |
| 0.58 | 开始颤 |

## 十·六、token 账怎么追（2026-11-07 加）

**问题**：面板显示缓存命中率 47.5%，但 qq 通道是 76.3%。

**拆分后才看出来是被 `internal:utility` 拉下来的**：

| 通道 | 次数 | 输入 | 命中率 |
|---|---:|---:|---:|
| qq | 82 | 1,448,500 | **76.3%** |
| **internal:utility** | **410** | **1,060,967** | **0.3%** |
| keepalive | 57 | 211,298 | 83.1% |
| memory_merge | 42 | 72,485 | 62.3% |

**排除 utility：47.3% → 75.8%。**

### 三个探针

| 探针 | 在哪 | 作用 |
|---|---|---|
| **`scope=utility:<函数名>`** | `plugins/ai_group.py::_caller_scope()` | DB 里能按调用来源拆 |
| **失败日志带 scope** | `_chat` 里每次重试 `logger.warning` | 日志里能看见谁在重试 |
| **暴涨判据** | `tools/deep_check.py::check_token` | >150 次 或 单次 >1500 token 就报 |

**健康灯显示**：

```
token: 24h 约 3.17 元 · utility 441次 命中0.3%
issues: utility 异常：utility 调用 441 次（平时 34~56）（未知来源×441）
```

**「未知来源」= 加 caller 标记之前的老数据（scope 是裸 `utility`）。**

### 查这类账的 SQL

```sql
select scope, count(*), sum(prompt_tokens), sum(cached_tokens)
from token_usage
where channel like 'internal:utility%' and date = date('now','localtime')
group by scope order by 3 desc;
```

## 十一·三、注意力漂移（2026-11-07 加）

```python
     − 累 × 0.42 − 丧 × 0.30 − 烦 × 0.15
```

| 平常 | active / balanced |
| 超我0.75（压着） | subtle / strict → **不注入** |

**超我压着时连「可以走神」都不给她说** —— 那轮她本来就不该飘，写了反而让她硬演。
