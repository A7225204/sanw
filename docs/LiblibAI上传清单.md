# 在上传 LiblibAI 时的填写清单

上传包：`D:\qq-ai-bot\data\liblib_rvc_upload.zip`
素材：56 段，9.8 分钟，48kHz 单声道 16bit（已去静音、降噪、响度归一）

---

## 一、模型命名

```
模型名      feiyu_voice
模型介绍    蓝色大肥鱼（鲸鱼娘）的音色，用于唱歌与说话
训练类型    RVC（声音转换）
```

RVC **不需要触发词**（那是 Stable Diffusion 的概念），如果页面有触发词栏，留空或填 `feiyu` 都行，不影响。

---

## 二、参数怎么填（能选就照这个）

| 项目 | 填法 | 说明 |
|---|---|---|
| 采样率 | **48k** | 唱歌用 48k 最清晰；若只能选 40k 就选 40k |
| 版本 | **v2** | v1 音质退回一档 |
| f0 提取 | **开**（f0G / f0D） | 唱歌必须开，否则跑调 |
| f0 算法 | **rmvpe** 优先，其次 harvest | pm 最差，别选 |
| batch size | 8（能调高就 12） | 显存大就调高 |
| 总 epoch | **200** | 9.8 分钟素材，150~250 都在合理区间 |
| 保存间隔 | 20 | 每 20 轮存一次，方便挑最好那轮 |
| 学习率 | 默认即可 | 平台一般不给改 |

**只训一次就好，别贪多** —— epoch 太高会"学死"，音色发假。

---

## 三、上传时可能遇到的三件事

**① 平台要求先切片**

如果它要求"音频切片"，我们的素材已经处理过：单条 1~20 秒、无静音、无杂音，直接传可切可不切。

**② 要求填"数据时长"**

填 9.8 分钟。部分平台有最低 10 分钟门槛，差 0.2 分钟可能被拒 —— 真被拒就告诉我，我从她历史语音里再补 10 条。

**③ 问"是否用于唱歌"**

有这一项就选**是**（对应 f0 引导 + 48k）。

```
· feiyu_voice_e200_xxx.pth    ← 主要文件，约 55MB
· added_xxx.index             ← 有就一起下（检索增强，可选）
```

下载后放到：

```
D:\qq-ai-bot\data\rvc_models\feiyu.pth
```

跟我说一声，我改链路：

```
ACE 生成 → demucs 分离 → RVC 变声（她的音色）→ 混回伴奏
```

RVC 比现在的 Seed-VC 快 5~10 倍，而且**只换音色、不改咬字** —— 你说的"唱出来和文字对不上"会好很多。
