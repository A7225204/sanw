# 主动消息系统 · 扫描分析报告

扫描范围：`D:\qq-ai-bot`（`desire.py`、`thoughts.py`、`plugins/ai_group.py`、`memory/*.json`）
结论先说：**这不是"定时发消息"插件，而是一套会自己积累冲动的心理模型**——比常见的"每 N 分钟发一条"先进一档。

---

## 一、它由四层组成

| 层 | 文件 | 作用 |
|---|---|---|
| 欲望驱动 | `desire.py`（136 行） | 想念 / 无聊 两条会随时间上涨的驱动，太累会压制冲动 |
| 念头池 | `thoughts.py`（170 行） | 记录"还没解决的事"（想学的、答应过的），主动开口时优先提 |
| 私聊主动 | `ai_group.py` L8139+ | 30 分钟摇一次，冲动够才发；9~22 点、间隔≥4h、每天≤2 条 |
| 群聊主动 | `ai_group.py` L365+ | 冷却 90 秒 + 每天 8 条上限 + 回复频率系数（0~100） |

状态文件：`memory/desire_state.json`、`memory/proactive_private.json`、`memory/thoughts.json`

---

## 二、核心机制（这部分是它的优势）

### ① 冲动不是掷骰子，是可解释的

```python
冲动 = 0.60 × (想念/100) + 0.40 × (无聊/100)
累 > 55 时：冲动 -= 0.55 × ((累-55)/45)
超过 0.55 才可能开口，之后还要过一次随机
```

所以"她为什么突然找你"有答案：

- 你 6 小时没说话 → 想念涨到 60+ → 冲动够 → 她开口
- 你刚聊完 → 想念掉 60 点 → 冲动不够 → 她不烦你
- 她熬到很晚（累 80+）→ 冲动被压掉大半 → 安静

### ② 关机期间也在"想"

```
tick() 按"距上次的时间"补算，重启后不会从零开始
关机 8 小时 → 想念 +216（封顶 100）→ 一开机她就特别黏
```

普通定时插件重启归零，这套不会。

### ③ 会记得"上次找你说过啥"

```
history 保留最近 20 条主动发言
prompt 里带上「你上次主动找他说：…」，避免重复同一个梗
```

### ④ 有"心事"再开口，不是干巴巴打招呼

```
thoughts.py 从聊天里自动识别「改天/下次/想要/答应」类句子
主动私聊时优先提这些：「你说的那个摆盘，我还在想呢」
```

这比"在吗""吃了吗"自然得多。

### ⑤ 有三重防烦人闸门

| 闸门 | 私聊 | 群聊 |
|---|---|---|
| 时间窗 | 9:00~22:00 | 全天（但受频率系数控制） |
| 间隔 | ≥4 小时 | ≥90 秒 |
| 每日上限 | 2 条 | 8 条 |
| 开关 | `/主动私聊 关` | `/频率 0~100` |

### ⑥ 成本近乎为零

```
驱动计算、念头提取、闸门判断：纯本地、不调模型
只有真正要发的那一次才调模型（deepseek，temp 0.95）
每天最多 2 次 → 约 0.001 元/天
```

### ⑦ 和身体状态联动

```
体力/饥饿来自 meal_state / sleep_state
太累 → 压制冲动；饿了 → 可能先提"我饿了"
```

## 三、和常见"主动消息插件"的对比

| 维度 | 常见定时插件 | 这套系统 |
|---|---|---|
| 触发 | 固定间隔 / 纯随机 | 冲动值 = 想念 + 无聊 − 疲劳 |
| 重启后 | 归零或立刻发 | 按时间补算，连续 |
| 内容 | 模板 / 随机话题 | 带最近聊天 + 上次说过的话 + 未完成的心事 |
| 频率控制 | 一个数字 | 时间窗 + 间隔 + 每日上限 + 频率系数 |
| 可解释性 | 无 | 日志里写明"冲动不足(0.42) 这次不找主人" |
| 成本 | 每次调模型 | 只在真正发时调 |

## 五、短板（我看到的）

| 短板 | 影响 | 建议 |
|---|---|---|
| 私聊参数写死 | 想改成"每天 3 条""间隔 2 小时"要改代码 | 提到 `.env` |
| 冲动只看想念/无聊 | 缺"刚发生了有趣的事想分享"这类驱动 | 加一个"事件驱动"权重 |
| 念头池靠关键词提取 | 隐晦的约定（"回头弄那个"）抓不到 | 可选 LLM 抽取（每天一次批量） |
| 没有"对方在忙"的判断 | 你明确说在渲染/开会，她仍可能来 | 读 activity_state，忙时降权 |
| 主动消息只发文字 | 少了语音/表情包的自然度 | 10% 概率配表情包 |
| 无效果反馈 | 哪条主动消息让你回了、哪条被无视，没统计 | 记录"发送后 10 分钟内是否回复"用于调权 |

## 六、一句话总结

> 它把"主动找你说句话"从**定时任务**变成了**心理状态的自然结果**：
> 想念会累积、无聊会累积、累了会闭嘴、有没说完的事会记得、说过的话不重复。
> 缺点是可调性一般（几个阈值写死在代码里），但骨架是对的，属于"越用越像人"的那类设计。
