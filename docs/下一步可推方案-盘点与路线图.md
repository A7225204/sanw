## 六、建议执行顺序

```
本周：P0-1 模板渲染 → P0-2 未认出清单 → P0-3 画图前卸 TTS
下周：P1-2 批量补标签（顺手把 P0-1 的模板接进 /做个表情包）
有余力：P1-1 长篇音声工作台（做 ASMR/有声书时再上）
```

**判断依据**：P0 三项都不动核心链路、当天能验收；P1 才涉及新服务或批量算力。
