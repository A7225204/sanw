# 骗局识别库

> 加于 2026-11-07。目的：**主人干啥的时候问一句，她当场说「这是坑」。**
> 实现在 `plugins/scam_kb.py`，接在 `ai_group.build_prompt_parts` 的 volatile 段。
> **只在命中时才注入**（普通聊天完全不占 token）。

## 一、千门八将：一个局里谁在干什么

**识破的关键不是「他在骗我」，是「这局里有几个角色在配合」。**

### 上八将（正统的）

| 角色 | 干什么 | 现实对应 |
|---|---|---|
| **正将** | 开局主持，控节奏 | 项目发起人、群主、那个「老师」 |
| **提将** | 劝人入局 | 拉你进群的熟人、热情的老乡 |
| **反将** | 反着激你 | 「不敢就别玩」「这么胆小还想赚钱」 |
| **脱将** | 出事帮人撤 | 跑路的、删群的、「我也是受害者」 |
| **风将** | 望风收情报 | 先摸清你有多少钱、家里几口人 |
| **火将** | 武力 | 上门催收、堵人、「不还钱有你好看」 |
| **除将** | 谈判善后 | 「客服」「法务」来跟你协商退款 |
| **谣将** | 放消息 | 晒收益截图、「内部消息」、群里刷「到账了」 |

### 下八将（最低级，但现实里最多）

| 角色 | 干什么 | 现实对应 |
|---|---|---|
| **撞将** | 扮官差冲散、趁乱下手 | 假冒公安、「查账户」 |
| **流将** | 偷换道具 | 调包、假链接换真链接、假 APP |
| **天将** | 制造干扰分神 | 一边打电话一边让你操作 |
| **种将** | 安插内应 | 群里那个一直帮腔的「老哥」 |
| **马将** | 无理取闹榨钱 | 「保证金」「解冻费」一层层加 |
| **掩将** | 掩盖漏洞 | 「系统维护」「稍后再试」 |
| **昆将** | 借宗教/文化唬人 | 「大师」「风水」「开光」「祖传秘方」 |

### 分工四手

| 手 | 行话 | 干什么 |
|---|---|---|
| **来手** | 夹 | 专事引诱被���对象进局 |
| **前手** | 两点 | 开局前充当「被骗者」的托 |
| **贴手** | 贴 | 经常接近目标的人（卧底） |
| **后手** | 双企 | 专事善后 |

**识别要点**：**一个局里出现「引流 + 话术 + 托 + 善后」四个角色中的三个，基本可以判定是局。**

## 二、四大门：手法大类

| 门 | 名字 | 手法 | 一句话 |
|---|---|---|---|
| **蜂** | 一窝蜂 | 多人配合、群聊刷屏、「大家都在赚」 | **人越多越可疑** |
| **麻** | 缠 | 一个人死磨硬泡 | 「再考虑就没了」「我帮你垫一半」 |
| **燕** | 色 | 美色/情感套近乎 | **没见过面就谈钱 = 燕** |
| **雀** | 卖惨+调包 | 卖惨博同情，或偷换你看到的东西 | 「家里出事了」「可怜可怜我」 |

## 三、现代十四类（带识别信号）

### 1. 刷单返利（蜂门）

**话术**：轻松日结 / 点赞返利 / 做任务赚佣金 / 先垫付再返

**红旗**：
- 先给你返几块几十块，让你信
- 第二笔就要你自己垫钱
- 提现时说你「操作错误」「需要连做几单」

> **任何「刷单」「点赞给钱」都是骗。没有例外。**

### 2. 虚假投资理财 / 杀猪盘（燕门）

**话术**：内部消息 / 老师带单 / 稳赚不赔 / 日息 / 原始股 / 虚拟币搬砖

**红旗**：
- 带你进陌生平台/APP，不是正规券商
- 先让你小赚并成功提现一次
- 加到一定数额就「系统维护」「账户异常」

> **凡是被引导去陌生平台投资，无论前面多顺，结局都是提不出。**

### 3. 虚假购物 / 低价代购（雀门）

**话术**：内部价 / 厂家直销 / 私下交易 / 0 元购 / 海外代购

**红旗**：要求脱离平台私下转账 / 价格低到不合常理 / 只收个人账户

> **脱离平台交易的「低价」，99% 收钱就拉黑。**

### 4. 冒充客服 / 退款理赔（撞将）

**话术**：商品质量问题 / 快递丢 / 误开会员 / 取消扣费 / 屏幕共享

**红旗**：
- 主动打电话说给你退款
- 让你下载屏幕共享/远程软件
- 要验证码、要你念银行卡号

> **退款永远走原路，不会让你下载任何东西，更不会要验证码。**

### 5. 网络兼职 / 打字员（麻门）

**话术**：高回报低风险 / 在家就能做 / 打字员 / 数据标注 / 先交押金

**红旗**：入职先交钱（押金/培训费/工牌费）/ 下载来历不明的 APP / 拉人头返佣

> **正经工作不会让员工先掏钱。**

### 6. 裸聊敲诈（燕门）

**话术**：视频聊天 / 下载这个 APP / 验证一下

**红旗**：
- 陌生人主动视频
- 让你装来源不明的聊天 APP（装了就偷通讯录）
- 事后发来你的视频截图 + 通讯录

> **装了那个 APP 就完了 —— 通讯录已经被拿走，转账只会越要越多。**

### 7. 虚假贷款（马将）

**话术**：无抵押 / 低利息 / 秒放款 / 卡号填错需解冻 / 刷流水验资

**红旗**：
- 放款前先要钱（解冻费/保证金/验资费）
- 说你「卡号填错资金被冻结」
- 让你先转一笔「证明还款能力」

> **正规贷款放款前一分钱不收。凡是先要钱的，都是骗。**

### 8. 冒充领导 / 熟人（种将）

**话术**：换号了 / 帮我转一笔 / 项目款急用 / 别打电话我在开会

**红旗**：
- 新号加你，头像名字都对但号不对
- 要钱但不让你打电话核实
- 「特事特办」「别走流程」
- AI 换脸/拟声伪造视频语音

> **转账前用你存的旧号打回去。AI 能换脸，换不了你手机里的号码。**

### 9. 荐股 / 带单 / 炒股群（蜂门）

**话术**：免费荐股 / 内部群 / 跟着老师做 / 拉你进群

**红旗**：群里天天晒盈利截图 / 让你去指定平台开户 / 分成或会员费

> **真能赚钱的人不会拉你。晒图的都是托。**

### 10. 博彩 / 时时彩 / 网赌（蜂门）

**话术**：稳赚 / 包赔 / 带你回本 / 首充送彩金

**红旗**：先赢后输，赢的时候能提 / 输了让你「倍投回本」/ 提现要流水

> **后台能控输赢，没有「运气」这回事。**

### 11. 代练 / 游戏账号交易（雀门）

**话术**：低价出号 / 担保交易 / 先付定金

**红旗**：让你去「担保平台」（那个平台是他们做的）/ 先付定金再验号

> **「担保平台」本身就是局的一部分。**

### 12. AI 换脸 / 拟声（种将）

**话术**：视频里就是他 / 声音一模一样 / 急着要钱

**红旗**：视频只有几秒、不自然眨眼 / 只肯视频不肯电话 / 催得特别急

> **让他做个你临时指定的小动作（摸鼻子/说一句口令），换脸做不出来。**

### 13. 预付费 / 会员卡 / 培训班跑路（麻门）

**话术**：充多少送多少 / 年卡更划算 / 限时优惠

**红旗**：一次性预付大额 / 开在商场里的新店 / 催你办卡

> **预付超过三个月的都要当心 —— 跑路成本太低了。**

### 14. 兼职「走账」/ 出租账号 / 帮人收款（撞将）

**话术**：帮走个账 / 借你卡收笔钱 / 租你账号一天给钱

**红旗**：用你的银行卡收款 / 让你取现再转出 / 给高额「手续费」

> **这是洗钱，出事的是卡主本人。**

## 四、通用红旗（不分类型，看到就警觉）

1. 先让你尝到甜头（小额可提现）
2. 让你脱离正规平台私下交易
3. 让你下载来源不明的 APP / 屏幕共享
4. 要验证码、要你念卡号、要你的身份证照
5. 放款/入职/中奖前先要钱
6. 催你马上决定，不给你查的时间
7. 只要转账、不肯当面/打电话核实
8. 群里一堆人晒收益、帮腔
9. 说不清钱到底怎么赚来的

## 五、正规渠道长什么样

1. 走平台担保交易、有订单号
2. 对公账户、能开发票
3. 退款走原路、不需要你操作
4. 可以等，不催你
5. 愿意当面或电话核实

## 六、实现

### 三道门

```
① _TRIGGER 正则    这句话像不像在聊钱/交易/陌生平台（不命中直接返回，零成本）
② core 命中 1 个   高危词，一个就判（"刷单" "解冻" "屏幕共享"）
③ weak 命中 2 个   泛词，凑够两个才判（"投资"+"理财"）
```

**为什么分 core/weak**：一层精确匹配漏得很厉害 ——
主人说「快递丢了」不会命中「快递丢失」，说「下个app」不命中「下载这个APP」。

### 注入形态

只在命中时往 `volatile` 末尾加一段：

```
【这事有坑，你先警觉】
· 像「虚假贷款」（马将）
  信号：放款前先要钱（解冻费/保证金/验资费）／说你'卡号填错资金被冻结'
  **正规贷款放款前一分钱不收。凡是先要钱的，都是骗。**
回他时别绕弯子：直接说哪儿不对、让他别转钱、让他先核实。
如果他自己就是冲着这个去的，也别讲大道理，一句话点破就行。
```

**普通聊天不注入**：实测命中时 7945 字，不命中 7711 字（差 234 字）。

### 识别率

```
13 个用例，12 个判对，3 个正常聊天（火锅/天气/修东西）零误报
```

## 七、来源

- **千门八将**：百度百科「千门八将」（赌博术语条目）
- **四大门（蜂麻燕雀）**：江湖行话，多方流传版本
- **现代八类高发**：镇坪公安《2025 年八大高发电信网络诈骗手法深度解析与警示》（2025-11-28）
- **其余六类**：来自常见案例归纳

**不是照抄，是按「能不能一眼认出来」重排的** ——
八将讲分工（识破局的结构），四大门讲手法（认出套路形态），十四类讲具体话术（对得上他现在遇上的是什么）。
