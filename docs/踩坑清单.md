## 一、改文件

### 1. heredoc 里的 `\n` 会变成真换行

**踩坑**：往 Python 源码里写 `"文本\n"`，bash heredoc 把 `\n` 解释成真换行，写进去变成：

```python
        "【本群黑话词典】
"
```

→ `SyntaxError: unterminated string literal`

**今晚踩了两次**（`group_lexicon.py`、`dashboard/index.html`）。

**解法**：

```python
BS = chr(92)
s = s.replace(..., '        + "' + BS + 'n".join(out)')
```

**或者**：用 `write` 工具直接写整个文件，不走 heredoc。

### 2. 一次改多处，中间 assert 失败 → **文件根本没写**

**踩坑**：一个脚本里做两个 `s.replace`，第二个 `assert old in s` 失败 →
**整个脚本退出，第一个替换也没写进文件** →
后续 `AttributeError: module has no attribute 'confidence'`

**解法**：**分步改，每改一处写一次文件、编译一次。**

### 3. 改字段名要**全局搜**

**踩坑**：把 `soul_aggregation.forces()` 里的 `"证据"` 改成 `"evidence"`，
**但 `ego_evidence.adjust()` 里还写着 `base["证据"]`** →
两边对不上 → `evidence` 永远是空的。

**同一个坑踩了两次**：`"证据"` 那次还导致前端 `v.toFixed(2)` 对字符串崩溃，**整页白屏**。

**解法**：改字段名前后各跑一次 `grep -rn "旧字段名" --include="*.py"`。

### 4. 备份要覆盖**所有被间接改到的文件**

**踩坑**：`verify.py` 的「消气」测试打三次 `insult`，
**那会通过 `emotion_residue.fire()` 喂给 `adler.hit()`**。
它备份还原了 `emotion_residue.json` 和 `hormones_state.json`，
**漏了 `adler.json`** → **每次跑 verify，她的自卑值被永久抬高一次**（0.33 → 0.83）。

**解法**：**列出所有会被间接写到的状态文件，逐个备份**。
或者干脆：测试用独立的临时目录。

## 二、git

### 5. `.gitignore` 对**已跟踪**文件无效

**踩坑**：把 10 个高频状态文件加进 `.gitignore`，`git status` 还是显示它们。

**解法**：

```bash
git rm --cached <file>     # 从索引移除，文件保留在磁盘
```

**而且要清全** —— 我第一次只清了 10 个，**还有 20 个在索引里没清**。

### 6. `git check-ignore` 的相对路径**按 cwd 算，不按 `GIT_WORK_TREE`**

**踩坑**：

```bash
GIT_WORK_TREE=memory git check-ignore -v activity_state.json
# 查的是 D:/qq-ai-bot/activity_state.json（不存在）→ 说没忽略

GIT_WORK_TREE=memory git check-ignore -v memory/activity_state.json
# ✅ 正确
```

### 7. 「有未提交」不等于「坏了」

**踩坑**：`self_check` 判 `未提交文件数 == 0` 才健康 ——
但 `长期记忆.json` 本来就在一直变 → **灯永远黄**。

**解法**：**看「最后一次 commit 距今多久」**，超过 2 小时（定时任务每小时一次）才报。

### 8. `core.quotepath=false`

**中文文件名默认会被 git 转义成八进制**（`\346\211\247...`），log 里没法读。

```python
"GIT_CONFIG_KEY_0": "core.quotepath",
"GIT_CONFIG_VALUE_0": "false",
```

## 三、前端 / 构建

### 9. `vite build` 的 `emptyOutDir: true` **会删非构建产物**

**踩坑**：`dashboard/webapp/` 里不只有 React 产物，还有 656MB 的 3D 模型和手写的 `room.html`。
一次 `npm run build` **把 `room-env.js` 删了、`room.html` 还原成旧版**。

**解法**：`emptyOutDir: false`。**代价是旧 assets 会堆积，手动清 `assets/` 即可。**

### 10. 面板的布局是 **JS 动态组织的**

**踩坑**：`index.html` 里写了个新 `<section>`，`curl` 能搜到、DOM 里没有。

**原因**：

```javascript
grid.innerHTML = "";          // 清空所有
grid.append(c1, c2, c3);      // 只 append 登记过的
```

**解法**：**新卡必须在 `layoutGrid()` 里 `append`**，否则被 `innerHTML = ""` 吃掉。

### 11. 三列对齐要看**总高度**，不是单卡高度

**踩坑**：加了 `cardGit`(240px)，第三列比中列多 240px，底边不齐。

**错的算法**：

```javascript
const avail = memH - dailyH - GAP;    // 685 - 959 - 16 = -290（负的）
git.style.height = Math.max(240, avail)   // 永远 240，但 daily 没缩
```

**对的算法**：**从 daily 里扣**。

```javascript
git.style.height = 240;
daily.style.height = dailyH - 240 - GAP;
```

### 12. `THREE is not defined` —— module 作用域的 import 不是全局

**踩坑**：`room.html` 是 `<script type="module">`（THREE 在 module 作用域），
`room-env.js` 是普通 `<script>`，**拿不到全局 THREE**。

**解法**：`RoomEnv.init({ ..., THREE })` —— **从外面传进去**。

### 13. 浏览器缓存：URL 加 `?v=` 参数

面板改了不生效，先确认不是缓存。**`/?v=$(date +%s)`**。

### 15. **验证要扫「注入点」，不是想当然**

**踩坑**：写「十层链路」时脑子里只有「激素推出来那条」。
**但 prompt 里还有一整套「记忆 → prompt」平行通道**（念头/心里的事/执念/梦），
它们的来源不是激素，是记忆和定时任务。

**解法**：**读源码，把每个 `lines.append` / `volatile +=` 列出来。**

### 16. **死代码不报错，只是安静地不干活**

**踩坑**：`GROUP_MEMES` 是空 `defaultdict`（0 条），
`if GROUP_MEMES.get(gid): lines.append("【群黑话】"...)` **一次都没执行过**。

**没有异常、没有日志、没有告警。**

**解法**：**检查函数返回空时，要区分「空是正常」和「取不到」。**

### 17. **检查工具自己会出错**

**解法**：**用 ASCII 名 + `tempfile.gettempdir()`；两个字段都看。**

## 五、理论落地

### 18. 把**韧性**当**自卑**，比漏判更坏

**踩坑**：阿德勒的 seed 扫 `persona_soul.json`，第一版连 `why` 字段一起扫 ——
把「被骂也不翻脸」「记仇不持久」算成自卑 → 初始值 0.66（该是 0.33）。

**那两条是韧性，不是自卑。**

**解法**：**只扫 `text`（主句），不扫 `why`（证据说明）。**

### 19. 阈值卡在边界上 = 模块白写

**踩坑**：自卑 2 条证据 / 分母 8 = 0.25，**刚好卡在注入阈值 0.3 下面，永远不说话**。

**解法**：**先算一遍典型值，确认它落在阈值上方。**

### 20. 「社交频率」冒充「归属感」

**踩坑**：「归属」用 `(最后一次对话距今 - 4) / 8`。
**主人一看就懵**：「我不是她主人吗，怎么还缺归属」。

**三个硬伤**：不分昼夜（夜里她睡了 8 小时被算成冷落）、不分对象（主人和群友混一起）、把社交频率当归属。

**解法**：**拆成两条通道** —— 归属看群、亲密看人。**马斯洛的归属是「被群体接纳」，不是「有一个亲密的人」。**

## 六、原则（从上面 20 条里抽出来的）

1. **改完就跑一遍** —— 今晚四个 bug 全是「改完跑一遍」发现的，**一个都不是定时巡检发现的**
2. **误报比不报更坏** —— 会让人怀疑整个系统
3. **测试会污染生产数据** —— 备份要覆盖所有间接改到的文件
4. **死代码不报错** —— 只是安静地不干活
5. **改字段名要全局搜** —— 改一处另一处没跟上

7. **验证要扫注入点** —— 不是想当然
8. **边界值要算一遍** —— 阈值卡在边界上等于没做

## 七、2026-11-07 白天（G.140/G.141 那轮）

### 21. 裸露关键词进词表，必须配否定检测

**踩坑**：`PLAN_HINTS` 里有裸「回头」，把「别回头」「散吧别回头」全判成「新计划」。
`_WHY_RULES` 也有「回头」→ 标成「承诺 0.75」→ 一刻钟 5 条假念头反复问主人。

**两个修法**：

1. 裸词改成带上下文的短语（`回头` → `回头聊/回头说/回头再/回头补`）
2. 加否定检测，**窗口取前 3 字不是 2**（「不要再想要」里「想要」前 2 字是「要再」含不到「不」）

### 22. 列表下标不能当实体 id

**踩坑**：`"related": [{"id": f"thought:{i}"}]` 用 `enumerate` 下标当 id，
后端详情又把冒号后面**当下标**查 `alive[627]` → 越界 → `None`。

**修法**：用实体自己的 id；解析时**先按 id 找，找不到再当下标**（兼容老链接）。

### 23. 写 UI 前先 grep 同目录的样式约定

**踩坑**：memory-viz 用内联 `style={panelStyle}`，**项目没装 Tailwind**。
我给新面板套了 Tailwind 类名 → 渲染成裸文字，主人说「变丑了」。

**修法**：新组件沿用同目录已有的样式常量，别自己造。

### 24. 字段在顶层还是嵌套要看清

**踩坑**：接口返回 `{node: {...}, thought: {...}}`，业务字段在**顶层**。
我写 `node.thought` → 面板能开但字段全空（0.00 / —）。

**修法**：写新组件前先 `curl` 一遍真实响应，看清字段在哪一层。

### 25. 只存摘要不存原文，事后无法核对

**踩坑**：`thoughts.json` 只存 40 字摘要，没原文没会话号。
她拿一条假承诺问「你应过本鱼…」，`trace` 能证明「没人说过」，**但查不到从哪冒出来的**。

**修法**：任何从对话里提取的派生数据（念头/执念/标签/关键词），都存
`src`（整句原文 ≥300 字）+ `scope`（会话号）+ `created`。

### 26. 注入不等于消耗，读过的要记账

**踩坑**：`prompt_line()` 只读不 `poke`，`poked` 永远 0，
同一条「心里的事」从早挂到晚反复问。

**修法**：取一条拿来用的函数，如果它影响「下次还选不选它」的权重，取的时候就要记账。

### 27. 推断要先验证，别当结论用

**踩坑**：看到「352 次、每 3 秒一次」，推断「重试重复记账，实际 117 次」，还写进了报告。
查 `record()` 开头就有空值跳过，实测 7067 → 7067。**那 352 次是真的。**

**修法**：涉及「账对不对」的判断，先读那段代码、再跑一次实测。
